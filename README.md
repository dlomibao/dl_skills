# dl_skills

[![Lint skills](https://github.com/dlomibao/dl_skills/actions/workflows/lint.yml/badge.svg)](https://github.com/dlomibao/dl_skills/actions/workflows/lint.yml)

Personal collection of custom [Claude Code](https://claude.com/claude-code) skills.

## Install

Using [Vercel's `skills` CLI](https://github.com/vercel-labs/skills) — works with Claude Code, Cursor, Codex, OpenCode, and 40+ other agents:

```bash
# Install all skills
npx skills add dlomibao/dl_skills

# Install a specific skill
npx skills add dlomibao/dl_skills --skill deck-architect

# Install globally (~/.claude/skills/) for Claude Code
npx skills add dlomibao/dl_skills -g -a claude-code
```

Or symlink directly without the CLI:

```bash
git clone https://github.com/dlomibao/dl_skills
cd dl_skills
bash scripts/install-skill.sh deck-architect    # one skill
bash scripts/install-skill.sh --all             # everything
```

## Layout

```
skills/<name>/
  SKILL.md          # required — frontmatter + instructions
  references/*.md   # optional — depth loaded on demand
```

Each skill is self-contained. The `SKILL.md` frontmatter tells the agent when to invoke it; the body is the instructions. See the [Anthropic skills spec](https://docs.claude.com/en/docs/claude-code/skills) for the authoring format.
